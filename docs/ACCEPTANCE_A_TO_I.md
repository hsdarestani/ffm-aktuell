## Additional account and operator checks

- A linked phone code is ten-minute, one-use, server-bound and limited to five checks. Wrong code increments attempts. Login via SMS cannot establish fresh authentication for account deletion, role grants or another phone link, and is unavailable for privileged/merchant/staff accounts.
- Review stars and text enter public aggregates only after moderation. A merchant-confirmed visit badge requires an actual separate confirmation record. A negative score is not, by itself, a rejection rule.
- Loyalty cards preserve issued reward/rule snapshots. Distinct concurrent visit codes cannot bypass the interval, and distinct reward codes cannot redeem one card twice.
- Department navigation and every server mutation enforce capabilities. Revocation takes effect on the next request. Root role changes need recent authentication and an audited reason.
- Homepage order/visibility is editable only by editorial capability, persists across migrations and validates the complete allowed module list.
- Provider-backed actions without configuration return a usable unavailable state. No fake payment, SMS, translated text, forecast, inventory verification or delivered notification is reported as real.

## Operations and restore rehearsal

CI uses a disposable localhost database. After HTTP acceptance, `scripts/ci-backup-restore.mjs` runs the PostgreSQL 16 container's actual `pg_dump` and restores into a separately named disposable database. It checks every public table's row count, entitlement functions and foreign-key presence, then removes the temporary private archive. It rejects any source host/database or container identifier outside this narrowly specified CI setup.

This rehearsal validates archive/restore compatibility and data structure. It does not claim an off-host production recovery drill, backup erasure policy, vendor ownership transfer, independent legal/accessibility audit or final stakeholder visual signoff. The isolated production deployment retains its existing backup, health-check and rollback gates.
